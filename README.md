# Kodex — apprendre JavaScript, React et Next.js (FR/EN)

Site 100 % statique (export Next.js). Progression et certificats : stockés dans le navigateur.

## Lancer
npm install && npm run dev

## Cloudflare Pages
- Build command : `npm run build`
- Build output directory : `out`
- Variable d'environnement : `NODE_VERSION=20`

## Ajouter du contenu
Tout est dans `lib/data.js` (cours > leçons > tests). Un test avec `expr`/`expect` exécute ton code dans un Worker ; un test avec `match` vérifie le code par expression régulière (React/Next.js).
Le nom du site : `SITE_NAME` dans `lib/data.js`.
